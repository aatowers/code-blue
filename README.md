# Code Blue Companion

A free, open-source companion for adult in-hospital cardiac arrest (code blue), built for licensed clinicians.

- ACLS prompts that follow the rhythm you select
- 2-minute CPR cycle timer, total code time, and time since last epinephrine
- One-tap logging of shocks (with energy), medications, and infusions
- Reversible causes (Hs and Ts) with situational medications
- A zoomable cardiac arrest algorithm
- A timestamped code summary you can copy or save as a PDF

## Install on iPhone

1. Open **https://aatowers.github.io/code-blue/** in Safari.
2. Tap the Share button, then **Add to Home Screen**, then **Add**.
3. Open Code Blue from your Home Screen.

It works with no signal after the first open and updates itself automatically. On Android, open the link in Chrome and choose **Install app** from the menu.

## Important

This app is an educational and reference tool for licensed healthcare providers. It is not a medical device and has not been reviewed or cleared by the FDA. It does not replace clinical judgment, institutional protocols, or current resuscitation guidelines, and it is not affiliated with or endorsed by the American Heart Association or any hospital. Verify every dose independently. Do not enter patient identifiers; data stays on the device and is not a medical record.

Doses and targets were checked against the 2025 AHA Guidelines for CPR and ECC and FDA prescribing information in November 2026.
