    Install Code Blue

    Add it to your Home Screen once. It then opens like an app, works with no signal, and updates itself.

    1. Tap the Share button in Safari's toolbar. On newer iPhones, tap the three-dot menu first.
    2. Scroll down and tap Add to Home Screen
    3. Tap Add, then open Code Blue from your Home Screen.
    1. Tap the browser menu (three dots, top right).
    2. Tap Add to Home screen or Install app.
    3. Open Code Blue from your Home Screen.
